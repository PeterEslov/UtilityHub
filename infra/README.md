# infra

Bicep-mallar för UtilityHub/Nordvik Energi, byggs ut fasvis:

- **Fas 0**: inget cloud-infra ännu — allt körs lokalt via Docker Desktop
- **Fas 1–3**: Service Bus (topics/subscriptions), Event Grid, Logic Apps
  Standard, Durable Functions-app, Application Insights
- **Fas 4**: Azure Container Registry, Azure Container Apps-miljö för de
  fyra mini-API:erna, API Management framför allt externt

Se roadmap-avsnittet i UtilityHub-arkitekturspecen för ordningen.
